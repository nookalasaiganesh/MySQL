Clauses 
--> are used to control how data is filtered , grouped ,sorted, or modified in SQL queries. They make SQL statements more meaningful and powerful.
1.WHERE CLAUSE
--> Filters records based on the specific conditions where clause can be used as comparison ,operators, logical operators and operators etc..,
syntax: 
SELECT COLUMN1, COLUMN2.. FROM TABLE-NAME WHERE CONDTION;
2.GROUP BY CLAUSE 
--> The group by clause is used to group rows having the same values in one or more columns, it is commonly used with aggregate functions such as min(), max(), sum(), count(), avg()
syntax:
SELECT COLUMN-NAME, AGGREGATE_FUNCTION(COLUMN-NAME) FROM TABLE-NAME GROUP BY COLUMN-NAME;
3.HAVING CLAUSE
-->The having clause is used to filter grouped records after group by clause. It is similar to where clause but it works on grouped instead of individual rows
syntax:
SELECT COLUMN-NAME, AGGREGATE_FUNCTION(COLUMN-NAME) FROM TABLE-NAME GROUP BY COLUMN-NAME HAVING CONDITION;
4.ORDER BY CLAUSE
-->The order by clause is used to sort the result set in ascending(ASC) or descending(DES)
syntax:
SELECT COLUMN-NAME FROM TABLE-NAME ORDER BY COLUMN-NAME;

Execution order of clauses 
1.FROM
2.WHERE
3.GROUP BY
4.HAVING
5.SELECT
6.ORDER BY
