Queries and sub-queries

Sub-query
--> A sub-query is a query inside another query
--> It is written inside parenthesis() and its result is used by the outer query
--> It is also called as inner query, nested query, inner select

Purpose of Sub-query
--> To break down complex problems into smaller queries
--> To use the result of one query as input to another
--> To avoid multiple steps(write in a single query instead of temp tables)

General syntax:
SELECT COLUMN-LIST FROM TABLE
WHERE COLUMN OPERATOR(SELECT COLUMN FROM TABLE WHERE CONDITION);

Types of sub-queries
1.Single row sub-query
--> This returns exactly one row/one column
--> They use comparison operators like =,>,<,>=,<=,!= 
Characteristics 
1. Returns only one value 
2. Can use single-value comparison operators
3. If sub-query returns no rows or multiple rows it causes an error
Syntax:
SELECT COLUMNS
FROM TABLE
WHERE COLUMN OPERATOR(SELECT COLUMN FROM TABLE WHERE CONDITION);

2.Multi row sub-query

(a) Multi-row sub-query IN
--> A multi-row sub-query returns more than on row
--> The IN operator is used to when you want to compare a value with multiple values returned by the subquery
Characteristics:
1. Returns multiple rows
2. Use the IN operator
3. Checks whether a value exists in the list returned by the sub-query
4. Equivalent to multiple OR condition
5. Most commonly used for matching values 
Syntax:
SELECT COLUMN FROM A TABLE 
WHERE COLUMN IN(SELECT COLUMN FROM TABLE WHERE CONDITION);

(b) Multi-row sub-query (ANY/SOME)
--> This returns multiple rows when using ANY/SOME
--> The condition is true if it matches at least one value returned by the sub-query
Characteristics:
1. Returns multiple values 
2. ANY and SOME are interchangeable 
3. Condition is true if any of the values satisfy the condition
4. Often used with IN, >ANY, <ANY, >=ANY .. Etc.;
Syntax:
SELECT COLUMN FROM TABLE 
WHERE COLUMN OPERATOR ANY/SOME(SELECT COLUMMN FROM TABLE WHERE CONDITION);

(c) Multi-row subquery ALL
-->The ALL operator means the condition must be true for all values returned by the sub-query
Characteristics:
1.Conditions must be true for all values in the sub-query result
2.Often used with >ALL,<ALL,>=ALL,<=ALL
3.>ALL means greater than the maximum value
4.<ALL means less than minimum value
Syntax:
SELECT COLUMN FROM TABLE
WHERE COLUMN OPERATOR ALL(SELECT COLUMN FROM TABLE WHERE CONDITION);

3.Nested sub-query
--> Nested sub-queries are sub-queries within sub-queries
--> They can be multiple levels deep and are executed from innermost to the outermost
Characteristics:
1. Multiple levels of nesting
2. Inner queries execute first
3. Can combine different types of sub-queries
4. Useful for complex conditions
Syntax:
SELECT COLUMN-LIST FROM TABLE
  WHERE COLUMN=(SELECT COLUMN FROM TABLE WHERE COLUMN=(SELECT COLUMN FROM TABLE WHERE CONDITION));

4.Co-related sub-query
--> Co-related sub-queries are sub-queries that reference columns from outer query
--> Unlike regular sub-queries that execute once
--> Co-related sub-queries execute once per each row processed by the outer query
Characteristics:
1. Reference column from outer query
2. Executes multiple times(once per outer row)
3. Cannot be execute independently
4. Often used with EXISTS/NOT EXISTS 
5. Generally slower than non-co-related sub-queries
Syntax:
SELECT COLUMN FROM TABLE1 OUTER_ALIAS
WHERE CONDITION(SELECT COLUMN FROM TABLE2 INNER_ALIAS
                       WHERE INNER_ALIAS.COLUMN=OUTER_ALIAS..COLUMN);

5.Exists/Not exists subquery
--> Exists is used to test whether a sub-query returns any rows
--> It returns TRUE if the sub-query returns at least one row , FALSE otherwise
--> Not exists return TRUE if the sub-query returns no rows 
Characteristics:
1. Returns TRUE/FALSE (Boolean result)
2. More efficient than IN for large datasets
3. Often used with co-related sub-queries
4. Stops execution as soon as first match is found
5. Select clauses in Exists doesn't matter(often use SELECT 1)
Syntax:
SELECT COLUMNS FROM TABLE1
WHERE EXISTS(SELECT 1 FROM TABLE2 WHERE CONDITION)
Syntax:
SELECT COLUMNS FROM TABLE1
WHERE NOT EXISTS(SELECT 1 FROM TABLE2 WHERE CONDITION);


mysql> CREATE TABLE Customers (
customer_id INT PRIMARY KEY, 
 customer_name  VARCHAR(50),  
city VARCHAR(50),  
customer_type VARCHAR(20)
); 

CREATE TABLE Products (  
product_id INT PRIMARY KEY, 
product_name VARCHAR(50),  
category VARCHAR(30),  
price DECIMAL(10,2)
);

 CREATE TABLE Orders (  
order_id INT PRIMARY KEY,  
customer_id INT REFERENCES Customers(customer_id),  
product_id INT REFERENCES Products(product_id),  
quantity INT,  
order_date DATE, 
amount DECIMAL(10,2)
);
