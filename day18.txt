
INTRODUCTION TO TRIGGERES:
---------------------------
A Trigger is a special type of stored program that automatically executes(fires) in 
response to the specific event. INSERT,UPDATE,DELETE occurring on a specified table.
Unlike a stored procedure. A trigger never called directly.

General Syntax:
DELIMITER //
CREATE TRIGGER trigger_name
{BEFORE|AFTER}{INSERT|UPDATE|DELETE}
ON table-name
FOR EACH ROW
begin
    --- trigger logic
    --- use new column name for inserted/update values.
    --- use OLD>column_name for delete/previous values.
END //
DELIMITER ;
